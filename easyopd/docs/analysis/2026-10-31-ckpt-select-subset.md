# 2026-10-31 选 ckpt 用哪个验证子集

- 代码：临时脚本，未入库；中间产物 `/tmp/ckpt_inv.json`（ckpt 清单）、`/tmp/M.npy`（35 个 ckpt × MATH-500 500 题逐题正确率）、`/tmp/meta.json`（节点本地，会丢）。评测结果来自 `experiments/07_opd_repro/scripts/evaluate.py` 在各 run 目录下的 details
- 状态：resolved
- 结论（一句话）：MATH-500 能在同一 run 内区分 ckpt（与金标 Spearman 0.89）；只用 L4+L5 的 262 题效果基本相同（0.87）；按区分度学出来的子集不比随机子集好，所以直接用 L4+L5。

## 问题

训练时每 20 步存一个 ckpt，需要一个验证集从中选最终 ckpt。要求：和报告集（AIME / AMC）的排序一致；题够多，噪声小；不和训练集重复；评测快。

## 方法

- 样本：35 个 ckpt，来自若干个 07_opd_repro run，每个都在 MATH-500 上有逐题结果。
- 金标：每个 ckpt 的 AIME24、AIME25、AMC23 三者平均正确率。三个集合合计 100 题，本身噪声不小，只能当近似。
- 指标：同一 run 内，子集正确率与金标的 Spearman 相关，再在各 run 之间取平均。只比同一 run 内的排序，是因为选 ckpt 只需要在同一 run 内比较。
- 子集学习：按逐题区分度挑题，用 leave-one-run-out 交叉验证（留出一个 run 测，其余 run 挑题），与同样大小的随机子集比较。
- 噪声：相邻 ckpt 在同一子集上逐题配对，算差值的标准误（SE）。

## 证据

### 难度与正确率

MATH-500 的 level（1–5）与逐题平均正确率的 Spearman 为 −0.555。

| Level | 题数 | 备注 |
|---|---|---|
| L1 | 43 | 平均正确率 0.90，强 ckpt 上接近饱和 |
| L2 | 90 | |
| L3 | 105 | |
| L4 | 128 | |
| L5 | 134 | |

### 同一 run 内与金标的 Spearman

| 子集 | 题数 | Spearman |
|---|---|---|
| MATH-500 全集 | 500 | 0.89 |
| L4+L5 | 262 | 0.87 |
| 按区分度学出的子集（LORO CV） | 同大小 | 不高于随机子集 |

### 相邻 ckpt 的配对 SE（L4+L5，avg@4）

1.1–1.8 分。semi100 两个 run 在 L4+L5 avg@4 上的曲线（step 20/40/60/80/100）：

| run | 20 | 40 | 60 | 80 | 100 |
|---|---|---|---|---|---|
| semi100_semi | 71.9 | 65.9 | 68.9 | 68.2 | 68.4 |
| semi100_opd | 69.5 | 73.4 | 73.4 | 72.9 | 72.5 |

相邻点差距大多在 1–2 个 SE 以内，所以选 ckpt 规则里加了「差距 < 1 SE 视为打平」。

## 排除的假设

- 「MATH-500 太简单，区分不了 ckpt」→ 排除，同 run 内 Spearman 0.89。
- 「挑正确率在 50% 左右的题区分度最高，应专门挑这类题」→ 学出的子集在留出 run 上不比随机子集好，样本量（35 个 ckpt）下挑题过拟合。没有采用。
- 「用 MATH 其余 4500 题的 L4 当验证集」→ 排除。与 DAPO 训练集重复 1/3 以上，见 [2026-10-31-dapo-contamination.md](2026-10-31-dapo-contamination.md)。
- 「从 AIME / AMC 里抽子集当验证集」→ 没有采用。题太少，抽走以后报告集更小，而且会带来选择偏差。

## 结论与根因

已验证：
- L4+L5 与全集的排序一致性基本相同，题数只有一半。
- 相邻 ckpt 差距常在噪声内，需要平滑和打平规则。

局限：
- 金标本身只有 100 题、单 seed，Spearman 的置信区间没算。
- 35 个 ckpt 来自少数几个 run，结论是否适用于别的模型对没有验证。

## 影响的决定

- 写进 [reference/eval-protocol.md](../reference/eval-protocol.md)：训练时验证用 L4+L5 抽 200 题，选 ckpt 用 L4+L5 全部 262 题 avg@4，用 3 点平滑和 1 SE 规则。
