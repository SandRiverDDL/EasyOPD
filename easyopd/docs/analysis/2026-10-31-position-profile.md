# 2026-10-31 OPD 信号随位置怎么变：轨迹内位置与句内位置

- 代码：`experiments/07_opd_repro/scripts/probes/position_profile.py`（新写；读 dump 和 top-k RKL 的写法照搬 `grad_token_stability.py`）
- 产物：`runs/train/07_opd_repro/vanilla_opd/1030_0745_opd100lr1_vanilla/analysis/position_profile/stats.txt`
- 状态：open（只看了一个 run、一个 student/teacher 配对）
- 结论（一句话）：student 和 teacher 的分歧在轨迹前部更高、后部更低，这一点在各长度段都成立；"越往后 teacher 熵 / 困惑度越高、margin 越小"在本数据里不成立，方向反而略相反。句首 token 的分歧和熵明显更高，但后期（step ≥ 150）这部分差异基本由"句首是哪些词"解释，位置本身的额外效应很小。

## 问题

用户听说的经验，以及自己看轨迹时的观察：

1. 同一条轨迹里，越往后 teacher 的 margin 越小、困惑度越高、熵越高；
2. 轨迹前部 student 与 teacher 的分歧更高；
3. 一句话的前几个 token 分歧更高。

要判断这些在本仓 vanilla OPD 的 token dump 里是否成立，并排除长度、幸存者偏差和 token 身份这几类混淆。

## 方法

- 数据：`vanilla_opd/1030_0745_opd100lr1_vanilla` 的 token dump，step 10 / 50 / 100 / 110 / 150 / 200。每步 32 题 × 8 条 rollout，T=1，回答上限 8192。step ≥ 110 的 dump 才有 student 熵和 top-k（K=20），所以 kl、ent_s、margin_t 只有这三步。step 10 有 38 条长度不足 64 的轨迹被丢弃（剩 218 条）。
- 指标（y 为采样到的 token）：
  - `lr` = log p_T(y) − log p_S(y)，`abs_lr` = |lr|；
  - `kl` = student top-20 上的反向 KL Σ p_S (log p_S − log p_T)，比单点 lr 噪声小；
  - `ent_t` / `ent_s`：全词表熵；`nll_t` = −log p_T(y)，即 teacher 在 student 前缀上的困惑度（对数）；
  - `margin_t` = teacher top1 概率 − top2 概率。最初用的是 logp 差，但 top2 的 logp 可低到 −20，均值被长尾主导（SE ±0.35），所以改成概率差。
- 控制：
  - 每条轨迹权重相同：先在轨迹内对每个位置桶求均值，再跨轨迹平均；
  - 相对位置（十分位）按长度分桶报告；绝对位置的开头表只用长度 ≥ 2048 的轨迹，保证每个桶是同一批轨迹；
  - 按 correct / wrong / truncated 分开；
  - `_res` = 指标减去该 token id 在同一步内的均值（出现 ≥ 20 次的 id），即扣掉"是哪个词"之后剩下的部分；
  - SE 是按题目（uid）做 bootstrap，因为同一题的 8 条 rollout 相关。
  - 去掉最后的 stop token 和 `<|endoftext|>` / `<|im_end|>`。
- 句子切分（启发式）：token 以换行结尾，或以 . ! ? 结尾且下一个 token 以空白开头，就算句末；纯空白 token 不计位置。"e.g. x" 会被误切，"3.5" 不会。step 200 有 92% 的 token 有句内位置，平均每条轨迹 192 句。
- 成本阶梯：CPU 级，直接读已有 dump，6 步共 4M token，单进程约 1 分钟。

## 排除的假设

- "越往后 teacher 熵 / 困惑度越高、margin 越小" → 在本数据的各步都不成立：后段 ent_t 和 nll_t 略低或持平，margin 略大（step 200：−0.029 ± 0.020、−0.082 ± 0.025、+0.018 ± 0.010）。可能的原因是这类经验来自 teacher 自己生成的长推理，或来自按 token 池化、长轨迹占主导的统计；这里没有验证。
- "前段分歧高是幸存者偏差（长轨迹混进后段）" → 不成立：按长度分桶后每段都是前高后低，并且用的是相对位置。

## 结论与根因

已验证（只适用于本 run：Qwen3-1.7B-Base student、vanilla OPD、lr 1e-6、每步 32 题；SE 来自 32 个 uid 的 bootstrap，单 seed）：

- 轨迹内分歧前高后低：step 200 时 abs_lr 后段比前段低 20–30%（correct 0.27 → 0.19，wrong 0.28 → 0.22），kl 低 25–35%；各长度段、对错轨迹都成立。
- teacher 熵在轨迹两端低、中间平，不随位置上升。
- 轨迹最开头（前 8 个 token）的巨大分歧只在训练早期存在，step 150 后消失。
- 句首 teacher 熵和分歧明显更高，但后期几乎都能由 token 身份解释。

仅推测：

- 早期开头分歧大，原因是 Base student 的开头格式；
- 中段 teacher 熵平台对应推理步骤里的分叉词。

局限：

- `_res` 的控制偏保守：一个 id 如果大多出现在句首，它的 id 均值本身就带着句首效应，扣掉均值会把位置效应一并扣掉。所以"位置额外效应小"只能当下界看。
- 句子切分是启发式的，LaTeX 公式内部没有句子概念，被算成长句的句中部分。
- abs_lr 是单个采样 token 上的估计，噪声大；kl 只有 step ≥ 110 才有。

## 影响的决定

- 按"句首 / 轨迹前段"给 OPD 加权，后期能得到的额外信息有限：句首信号基本可以用 token 身份或 teacher 熵（`ent_t`）代替，不需要单独的位置特征。
