# 2026-10-31 后期 OPD 的"二选一"位置：换 token 会不会改变答对率

- 代码：`experiments/07_opd_repro/scripts/probes/fork_probe.py`（生成 / teacher 打分 / 续写 / 统计）、`fork_probe_analyze.py`（追加统计）、`run_fork_probe.sh`（单节点 8 卡包装；两节点各起一次）
- 产物：`runs/train/07_opd_repro/fork_probe/1031_0548_fork300/`（`stats.txt`、`forks_merged.jsonl`、`shards/`、`README.md`）；冒烟 `1031_0541_smoke/`
- 状态：open（只测了一个 ckpt、一个 seed）
- 结论（一句话）：在 student 的"二选一"位置强制换 token，绝大多数分叉对最终答对率没有可测影响；平均来看，选 teacher 偏好的那个也不提高答对率（效应 ≈ 0）。经多重检验校正（BH，FDR 0.05）后只有 3 / 612 个分叉（约 0.5%）能确认是真决策点，都是数学内容上的分叉（`\frac` 对 `\text`、`+` 对 `=`、半径 `1` 对 `7`）。（2026-10-31 更正：初版未做多重校正，把 12 个 p<0.05 都当成显著，并写成"约 1.5%"，是错的。）

## 问题

token dump 分析显示：OPD 训练到 200 步时，student 熵在 0.5–1 的位置只占 11% 的 token，却拿走 44% 的信号。这些位置大多是"二选一"：student top-2 的质量中位数为 0.95，teacher top-1 有 97% 落在 student 的 top-2 里。有两个假设需要区分：

- H1：两个候选基本是等价写法，选哪个都不影响能否答对。此时 OPD 在这里的梯度只是在对齐风格，对准确率没有用。
- H2：其中有一部分是决策点，选 teacher 偏好的那个更容易答对。

dump 不能直接回答这个问题，因为里面没有 prompt，也没法续写。所以新写了反事实分叉实验：截断前缀、分别强制两个候选，各续写 16 次，比较答对率。

## 方法

- 模型：student 为 `vanilla_opd/1030_0745_opd100lr1_vanilla` 续训到 step 200 的 hf ckpt；teacher 为 Qwen3-4B（non-thinking）。
- 采样：沿用训练协议，T=1、top_p=1、回答上限 8192，chat 模板与训练一致（token id 直接喂给 vLLM，不重新分词）。
- 题目：从 `train_en.parquet` 随机抽 1024 题（seed 0），每题生成 8 条 rollout。只保留答对 2–6 条的题，共 306 题，约占 30%。
- 候选位置，需同时满足：
  - student top-2 质量 ≥ 0.9，第二名 p₂ ≥ 0.1；
  - 两个候选都不是 stop token；
  - teacher 对两者的偏好差 |log q_a − log q_b| ≥ log 2。

  teacher 用 HF bf16 前向计算。
- 分叉类型：teacher 偏好 student 的第二名记为 disagree，偏好第一名记为 agree。每题最多取 2 个分叉，两类交替、来自不同的 rollout，共 612 个分叉（各 306）。
- 续写：对每个分叉，分别把 T（teacher 偏好的 token）和 O（另一个）接在前缀后，各续写 16 次。续写预算为 8192 − t − 1，截断率 1.0%。分叉位置平均在第 990 个 token，约为全长的 47%。
- 统计量：
  - 每个分叉算 Δ = acc_T − acc_O。
  - 真实异质性：Var_true(Δ) = Var_obs(Δ) − mean(抽样方差)，其中抽样方差用无偏估计 p(1−p)/15 × 2；对分叉做 bootstrap 求 CI。
  - 单个分叉的显著性用置换检验（16 对 16）。
  - 置换检验是离散的，偏保守，所以另做校准零假设：两支都从合并后的答对率按二项分布模拟一遍，看 p<0.05 的比例应是多少。
- 耗时：两节点 16 卡，墙钟约 22 分钟（gen 约 6 分钟，teacher 打分约 20 秒，续写约 8 分钟）；.79 比 .80 晚启动 3 分钟。

## 证据

总体结果（612 个分叉，每支 16 次续写，两支的平均答对率为 0.42）：

| 分叉类型 | n | 平均 Δ = acc_T − acc_O | 真实 sd(Δ) [95% CI] | 置换 p<0.05 | \|Δ\| ≥ 0.5 |
|---|---|---|---|---|---|
| 全部 | 612 | +0.000 ± 0.006 | 0.065 [0.020, 0.092] | 2.0% | 0.8% |
| disagree | 306 | +0.016 ± 0.009 | 0.077 [0.013, 0.112] | 2.3% | 1.3% |
| agree | 306 | −0.015 ± 0.008 | 0.046 [0.000, 0.086] | 1.6% | 0.3% |

- 单分叉显著性要做多重校正（2026-10-31 更正，初版这里算错了）：
  - 零假设模拟：两支都按该分叉的合并答对率做二项抽样，用 Fisher 检验，重复 200 次。p<0.05 的期望约 7.2 个，95% 范围 [2, 13]；p<0.01 的期望约 1.1 个，范围 [0, 3]。
  - 实测：p<0.05 有 12 个（Fisher 11 个），在零假设范围内；p<0.01 有 5 个（Fisher 4 个），略超。
  - BH 校正（FDR 0.05）后只剩 3 个：`\frac` 对 `\text`（p=3e-6）、`+` 对 `=`（4e-5）、半径 `1` 对 `7`（2e-4）。Bonferroni 下剩前 2 个。
  - `not`/`Not`、`**`/`**,`、`This`/`Let` 这类单个 p<0.05 的分叉是假阳性。
  - 每支 16 次续写时，单分叉 Δ 的标准误约 0.17，只能逐个确认 |Δ| ≳ 0.5 的大效应。
- 把 teacher 偏好和 student 名次分开看：
  - disagree 时 T 是 student 的第二名 b，agree 时 T 是第一名 a。
  - 由此得到 teacher 偏好的效应 ≈ (0.016 − 0.015)/2 ≈ 0。
  - 而"选第二名 b 比选第一名 a"在两类分叉里方向一致：acc(b) − acc(a) = +0.015 ± 0.006（2.6σ）。原 rollout 采到 a 的分叉是 +0.012 ± 0.007（n=444），采到 b 的是 +0.026 ± 0.014（n=144）。这个效应原因不明，强度只有 2.6σ，不作为结论。
- 按 teacher 偏好强度分（disagree 分叉的平均 Δ）：

  | \|log q_a/q_b\| | n(disagree) | 平均 Δ |
  |---|---|---|
  | [0.69, 1.5) | 147 | −0.002 ± 0.012 |
  | [1.5, 3) | 108 | +0.031 ± 0.016 |
  | ≥ 3 | 51 | +0.033 ± 0.021 |

  teacher 偏好很强时有约 +3pp 的正向趋势，但都在 2σ 以内。
- 按候选 token 类型分（两个候选同类时才归入该类）：

  | 类型 | n | 真实 sd(Δ) | \|Δ\| ≥ 0.375 | disagree 平均 Δ |
  |---|---|---|---|---|
  | 数字 | 46 | 0.121 | 6.5% | +0.052（n=29） |
  | 英文单词 | 197 | 0.084 | 3.6% | +0.033（n=100） |
  | 符号 / LaTeX | 168 | 0.000 | 1.2% | +0.017（n=77） |
  | 混合 | 194 | 0.056 | 2.1% | −0.017（n=94） |

- 效应最大的几个分叉（来自 `stats.txt`）：
  - `\text` 与 `\frac`（"New Time = \…"），+0.81；
  - 半径取 `7` 还是 `1`（teacher q=1.00 偏好 `1`），+0.69；
  - 求和写 `5` 还是 `2`，+0.56。

  这些都是数学内容上的决策点，不是风格词。

## 排除的假设

- "二选一位置大多是决策点（H2 的强形式）"不成立：
  - 真实 sd 只有 0.065，CI 上限 0.092；
  - |Δ| ≥ 0.5 的只有 0.8%；
  - 平均而言，选 teacher 偏好的 token 不提高答对率。
- "这些 Δ 全是噪声（H1 的强形式）"也不成立：
  - 真实方差 CI 下限 0.0004 > 0；
  - 有 3 个分叉通过 BH 校正。（初版写"显著比例是零假设的 4 倍"，零假设算错，已撤回。）

## 结论与根因

已验证（只适用于本 ckpt、本 teacher、本筛选口径、单 seed，以及训练集上的 306 道中等难度题）：

- 在 student 二选一、teacher 有明确偏好的位置，选哪个候选对最终答对率的影响很小：典型幅度约 6pp，绝大多数接近 0。H1 为主。
- 按 teacher 的偏好走，平均不提高这个 student 的答对率。在这些位置上，OPD 的梯度主要在对齐写法，对准确率贡献有限。这和"后期 KL 不降、准确率只缓慢上涨"一致，但不能证明二者有因果关系。
- 能逐个确认的真决策点只有 3 / 612（BH 校正后），都是数学内容；比例的上限受每支 16 次续写的功效限制，测不准。

仅推测（没有验证）：

- "teacher 偏好越强越有用"的趋势（+3pp，<2σ）；
- 第二名 b 优于第一名 a 的 +1.5pp（2.6σ）。

两者都需要换 seed 或扩大样本再确认。

局限：
- 只看了最终答对率，没看长度、格式等其他价值。
- 单个 token 的影响可能被后续自我修正吸收，所以 Δ≈0 不等于"该 token 在训练里没有用"。
- 题目来自训练集，step 200 时已见过约 6400 题，可能包含这里的部分题目。
- 只测了 step 200，没有和早期 ckpt 对比。

## 影响的决定

- 如果要做"只在决策点上加权 OPD"之类的干预，在这个口径下能确认的位置只有约 0.5%（3 / 612）。要先找到能廉价识别它们的特征（数字类 token、teacher margin 大），并用更大样本验证，才值得进入训练实验。
