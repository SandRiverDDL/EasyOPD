# 2026-10-31 后期 OPD 的 KL 平台：二选一位置是不是"学不会"

- 代码：`experiments/07_opd_repro/scripts/probes/kl_trend_by_group.py`、`abs_by_group.py`、`fix_prefix_overfit.py`、`noise_scale.py`（均为新写）
- 状态：open
- 结论（一句话）：容量不足（H-c）已排除。step 200 时，二选一位置每 token 的 KL 仍是其余位置的约 2.3 倍，而且 100 步后几乎学不动了。按位置拆开测噪声尺度后发现，二选一位置的 B_simple ≈ 644 题，其余位置 ≈ 44 题；batch 32 时二选一位置的梯度约 95% 是噪声。它的期望梯度不为 0，但很小，只占总 |G|² 的 2%。所以二选一位置单个样本的梯度大，主要大在噪声上，题与题之间大量抵消（H-b 对二选一位置成立）。其中约一半噪声来自 token 采样，用全分布期望可以去掉；去掉后 B_two 仍为 301，是其余位置的 7 倍，说明主体是不同前缀下方向不一致（第 6 节）。其余位置的 KL 也持平，原因仍未解释。
- 更正：第 1 节最初的解读"二选一位置在降、其余位置持平，所以二选一不是瓶颈"看的是总量和相对斜率，结论不成立，见第 4、5 节。

## 问题

vanilla OPD（`runs/train/07_opd_repro/vanilla_opd/1030_0745_opd100lr1_vanilla`，Qwen3-1.7B-Base-imend ← Qwen3-4B，32 题 × 8，8192，lr 1e-6）在 96–200 步 token KL 基本持平（约 0.14），但 grad_norm 稳定在约 0.56。早先的 dump 分析发现信号集中在 student 二选一位置（student 熵 0.5–1 一桶占 11% token、44% 信号），于是提出三个解释：

- H-a：teacher 在这些位置的偏好无法从前缀预测，对 student 不可学；
- H-b：能学，但在线梯度噪声太大，KL 卡在噪声底；
- H-c：1.7B 的容量 / 优化本身不够。

三分法是本仓自己提出的框架，没有文献出处，三者也不互斥。

## 证据

### 1. 在线 dump 按位置分组的 KL 走势（描述性统计）

二选一规则同 `fork_probe.py candidates()`：student top-2 质量 ≥ 0.9、p2 ≥ 0.1、两个候选都不是停止符。KL 为 student top-20 上的逐 token RKL，按 token 平均。dump 只有 step ≥ 110 带 top-k，取 110–200 共 10 个点。

| | 斜率 / 100 步 | 相对均值 |
|---|---|---|
| kl_all | −0.0017 ± 0.0102 | −1.2% |
| kl_two（二选一位置，约 9–10% token，KL 占 20%） | −0.0356 ± 0.0089 | −11.8% |
| kl_rest（其余位置） | −0.0004 ± 0.0108 | −0.3% |
| frac_two | +0.0118 ± 0.0060 | +12.3% |

- 标准误忽略了相邻 step 的自相关，偏乐观。
- 组成在变：二选一位置的比例随 student 熵回升而增加，且与 kl_two 负相关（r = −0.80）。把 frac_two 作为协变量回归后，kl_two 的步数斜率仍为 −0.023 ± 0.008 / 100 步（约 −8%）。
- 解读：H-a 的预测是"二选一位置不降、其余位置在降"，实际相反。KL 平台主要来自占 80% KL 的其余位置。

### 2. 固定前缀离线过拟合（对应 Zhang et al. 2017, arXiv 1611.03530 的"能否拟合"）

数据：`fork_probe` 1031_0548 的 step-200 rollout，按题划分 train big 256 / small 32 / heldout 128 题；teacher top-20 在 prep 阶段预先算好。产物 `runs/train/07_opd_repro/fix_prefix/1031_0751_overfit/`。

| run | 训练集 kl_two | 留出集 kl_two | 训练集 kl_all | 留出集 kl_all |
|---|---|---|---|---|
| two_small lr1e-5（640 步） | 0.306 → 0.025（−92%） | 0.293 → 0.342（+17%） | 0.173 → 0.132 | 0.159 → 0.207（+30%） |
| two_big lr1e-5（768 步） | 0.284 → 0.095（−66%） | 0.293 → 0.298（+2%） | 0.154 → 0.124 | 0.159 → 0.171（+7%） |
| two_big lr1e-6 | 0.284 → 0.162（−43%） | 0.293 → 0.274（−6%） | 0.154 → 0.127 | 0.159 → 0.153（−4%） |
| all_big lr1e-5（全部位置） | 0.284 → 0.193（−32%） | 0.293 → 0.314（+7%） | 0.154 → 0.102（−34%） | 0.159 → 0.158（−1%） |

- H-c 排除：固定前缀下 1.7B 能把训练集二选一 KL 降掉 92%。
- 留出集不降不是二选一位置特有的：all_big 训练全部位置，训练集 kl_all 降 34%，留出集 kl_all 也只降 1%。256 题的离线训练整体处在记忆区，所以这组实验不能用来支持 H-a。
- lr 1e-6（与在线相同）是唯一留出集略降的设置（−4% 到 −6%），单 seed，不下结论。

### 3. 梯度噪声尺度（McCandlish et al. 2018, arXiv 1812.06162）

B_simple = tr(Σ) / |G|²，用论文附录 A.2 的大小 batch 无偏估计。单位是"一道题及其 8 条 rollout"，与训练的采样单位一致。数据为 step-200 student 的 rollout（即 step 201 的在线数据），512 题；损失为 vanilla OPD（A = log q − log p，on-policy 时 PPO ratio = 1）。产物 `runs/train/07_opd_repro/noise_scale/1031_0930_n512/`。

| 量 | 值 |
|---|---|
| B_simple | 65 ± 5 题（8 个 shard 的 jackknife：63–68） |
| batch 32 题时 \|G\|² 占梯度平方的比例 | 33% |
| 预测 batch 32 的 grad norm | 0.67（日志 step 197–200 为 0.54–0.58） |

- 按论文的模型，所需步数 S ≈ S_min(1 + B_noise/B)：B = 32 时约为 3.0 S_min，B = 128 时约为 1.5 S_min。加大 batch 最多把每步进度提高约 2 倍，不是数量级的差别。
- 论文的警告：B_simple 假设 Hessian 条件良好，真实的临界 batch 可能偏离。
- |G|² 显著大于 0，说明在 step 200 的在线分布上，参数空间里仍存在一致的下降方向，模型并没有停在驻点。

### 4. 每 token 绝对值：早期对比后期（描述性统计，更正第 1 节的解读）

`abs_by_group.py` 对每个 dump step 统计逐 token 的量。step < 110 的 dump 没有 top-k，用"采样 token 的 p 在 0.1–0.9"作代理；在 step ≥ 110 上，这个代理覆盖了 97% 的精确二选一位置。k1 = log p − log q（采样 token 上的单样本 KL 估计）。

| step | 代理位置 k1 | 其余位置 k1 |
|---|---|---|
| 20 | 1.166 | 0.206 |
| 100 | 0.394（20→100：−66%） | 0.052 |
| 200 | 0.348（100→200：−12%） | 0.059 |

用精确规则和 top-20 RKL 算，step 200 时二选一位置为 0.288，其余位置为 0.125，前者每 token 约是后者的 2.3 倍；逐 token 的信号²（top-k 上的方差项）分别为 0.231 和 0.037，约 6 倍。

- 二选一位置早期学得很快，100 步后几乎停住，而它每 token 离 teacher 仍最远。第 1 节"二选一位置在降、其余位置不动"只是相对斜率，按绝对值看，二选一位置才是没学完的部分。
- 其余位置的 k1 在 100 步后也不再下降。

### 5. 按位置拆分的梯度噪声尺度

方法同第 3 节，同样的 512 题（seed 0）× 8 条 rollout。损失只保留二选一位置（`--mask two`）或只保留其余位置（`--mask rest`）。归一化常数相同，所以 G_two + G_rest = G_all。按位置加 mask 是本仓对 McCandlish et al. 的扩展，估计量本身不变。产物：`runs/train/07_opd_repro/noise_scale/1031_0948_mask_two/`、`1031_0948_mask_rest/`。

| 量 | 二选一位置 | 其余位置 |
|---|---|---|
| token 占比 | 9.9% | 90.1% |
| \|G\|²（± jackknife SE） | 0.0032 ± 0.0005 | 0.146 ± 0.010 |
| tr(Σ) | 2.04 | 6.45 |
| B_simple（题） | 644 ± 107 | 44 ± 3 |
| 题间平均余弦 1/(1+B) | 0.0016 | 0.022 |
| batch 32 时信号占比 | 4.7% | 42% |
| 每个选中 token 的期望梯度 \|G\|/占比 | 0.57 | 0.43 |
| 每个选中 token 的噪声 √tr(Σ)/占比 | 14.4 | 2.8 |

- 二选一位置的期望梯度不为 0（|G|² 约为 SE 的 6 倍），但每 token 只比其余位置大约 1.3 倍；噪声每 token 大约 5 倍。之前看到的"二选一位置梯度大"，大的主要是噪声部分。
- 题与题之间，二选一位置的梯度余弦是其余位置的 1/14，也就是说不同前缀把参数往不同方向推，相互抵消。按 S ≈ S_min(1 + B/batch)，batch 32 下二选一部分每步只有约 1/21 的有效进度。
- 合起来的更新几乎全部来自其余位置：|G_two|² 只占 |G_all|² 的 2%，G_two 与 G_rest 的余弦为 −0.04（由 |G_all|² − |G_two|² − |G_rest|² 反推），基本正交。
- 证据边界：单个 checkpoint（step 200），单 seed；B_simple 假设 Hessian 条件良好；没有测早期 checkpoint，所以不知道二选一位置的 B 是否在训练中变大。

### 6. 二选一位置的噪声来源：采样 token 还是前缀间不一致

这一节要分清二选一位置的噪声从哪来：是"采到哪个 token"（a），还是不同前缀把参数推向不同方向（b）。

做法：`noise_scale.py --mask two --est exact`，其余设置与第 5 节完全相同。在每个二选一位置，把采样 token 的那一项换成它在 y_t ~ p(·|前缀) 下的全词表期望 Σ_v p_v(lp_v − lq_v)∇lp_v。这相当于只对 y_t 做 Rao-Blackwell 化，前缀不变。这个做法是本仓的扩展，没有直接出处。产物：`runs/train/07_opd_repro/noise_scale/1031_1512_mask_two_exact/`。

第一次运行有 2 个 shard 因 OOM 失败，但 stats 照样出了结果，那次结果作废。修复：lm_head 只计算选中的行；stats 阶段加断言，题数不齐就报错。

| 量 | 二选一位置，采样 | 二选一位置，期望 | 其余位置，采样 |
|---|---|---|---|
| \|G\|² | 0.0032 ± 0.0005 | 0.0033 ± 0.0004 | 0.146 ± 0.010 |
| tr(Σ) | 2.04 ± 0.08 | 0.99 ± 0.04 | 6.45 ± 0.13 |
| B_simple（题） | 644 ± 107 | 301 ± 30 | 44 ± 3 |
| 题间余弦 | 0.0016 | 0.0033 | 0.022 |
| batch 32 时信号占比 | 4.7% | 9.6% | 42% |

- 内置检查通过：两种估计器的期望相同，实测 |G|² 在误差内一致（0.0032 对 0.0033）。
- (a) 约占二选一位置噪声方差的一半：tr(Σ) 从 2.04 降到 0.99。
- 去掉 (a) 之后，B_two 仍为 301，约是其余位置的 7 倍；题间余弦仍只有其余位置的约 1/7。其余位置没有做期望化，做了的话 B_rest 只会更小，所以 7 倍是保守估计。差距的主体是 (b)：在二选一位置，不同题、不同前缀下的期望梯度方向本身就不一致。
- 证据边界：剩下的 tr(Σ) 里还包含同一道题 8 条 rollout 前缀不同带来的方差，不全是 teacher 偏好随题变化；只测了 step 200，单 seed。

## 排除的假设

- H-c（容量 / 优化）→ 固定前缀能拟合到训练集 −92%，排除。
- H-a 的强形式（二选一位置的期望梯度为 0，完全不可学）→ 第 5 节测得 |G_two|² 约为 SE 的 6 倍，不成立。弱形式（可学的部分很小，大部分偏好随前缀变化）得到第 6 节支持：去掉 token 采样噪声后，B_two 仍为 301，是其余位置的 7 倍。离线留出集不降对所有位置都成立，不能用来支持或反驳 H-a。

## 结论与根因

已验证：
- H-c 不成立。
- 按每 token 绝对值，二选一位置离 teacher 最远（top-k RKL 0.29 对 0.12），20→100 步降了约 66%，100→200 步只降约 12%。
- 二选一位置的梯度噪声尺度约 644 题，是训练 batch（32 题）的 20 倍；其余位置约 44 题。二选一位置后期学得慢，与"每步更新里它的有效信号只有约 5%，题间梯度相互抵消"一致。
- 每步更新的方向 98% 由其余位置决定。
- 二选一位置的噪声约一半来自 token 采样，换成全分布期望后 B_two 降到 301；另一半来自前缀之间方向不一致，换估计器消除不了（第 6 节）。

未解释：
- 其余位置的 batch 32 信号占比有 42%，KL 却同样不降。可能是 lr 太小、Adam 的有效步长、曲率导致的震荡、在线分布随 student 移动（目标在变）等，都还没有测。
- 二选一位置早期为什么学得快：没有测早期 checkpoint 的 B_two，不知道是早期信号更强，还是早期学掉的是另一类位置。

作废：两版线性探针（`fix_prefix_overfit.py probe`）。所有候选对共享一个方向、没有 control task（Hewitt & Liang 2019, arXiv 1909.03368 要求的），结论不可用。

## 影响的决定

- 不再用"二选一位置的期望梯度为 0、完全学不会"作为后续方法设计的前提；要针对的是二选一位置的低信噪比。
- 尚未起跑的直接检验：（1）在 step 50 等早期 checkpoint 上重复第 5 节，看 B_two 是否随训练变大；（2）从 step 200 续训，对比 batch 32 与 batch 128（同样本量）下二选一位置的 KL。
